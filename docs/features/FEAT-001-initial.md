# FEAT-001: 어린이집 등원 준비 대시보드 UI · API · 상태 계약

## 1. 목적과 동작
- 헤더 왼쪽에 사각 아날로그 시계를 배치합니다. 두 테마 모두 12를 맨 위에 두고 1부터 12까지의 숫자를 시계 방향으로 30도 간격으로 배치합니다. 각 숫자는 똑바로 서며 서로 겹치지 않습니다. 중앙에는 윤곽을 준 테마 캐릭터, 검은 시침·분침과 빨간 초침을 표시합니다. 초침은 1초마다 갱신됩니다. 전체 날짜와 오늘·내일 예보를 날씨 카드에 표시합니다. 부모 설정은 카드 밖 오른쪽 위에 둡니다. 진행률의 아기상어는 다음 단계가 생기면 짧게 앞으로 움직입니다. 전체 완료, 앱의 움직임 감소 또는 시스템 모션 감소 상태에서는 수영 움직임을 멈춥니다.
- 기본 아기상어 테마는 마스코트 몸통의 노란색을 헤더·진행률·앱 테마색에 사용하고, 배경·완료 카드·도장은 밝은 노랑과 짙은 황갈색으로 구분합니다. 부모 설정에서 뽀로로를 선택하면 해당 테마의 파란색 헤더와 앱 테마색을 적용합니다.
- 글꼴은 두 테마 모두 Pretendard Variable 1.3.9를 사용합니다. 제목은 Bold(700), 본문은 Regular(400), 자간은 -0.02em입니다. HTML의 `<head>`에서 공식 CDN 스타일시트를 불러옵니다. 앱 셸과 함께 캐시한 WOFF2로 오프라인에서도 같은 글꼴을 표시합니다. 배포 묶음에는 글꼴 라이선스 고지를 포함합니다. [Pretendard 공식 웹폰트 안내](https://github.com/orioncactus/pretendard#웹폰트)
- 정적 PWA 자산(`web/`)으로 갤럭시 탭 S7에서 시계·Open-Meteo 날씨·카운트다운·4단계 도장·1.5초 취소·3초 부모 설정을 제공합니다. 공개 기본 호칭은 `친구야`이며, 부모 설정에서 호칭·출발 시각·테마·그림을 편집합니다. 기기에 저장한 사용자 호칭은 업데이트 후에도 보존합니다.
- 시계 배경은 선택한 테마에 등록한 마스코트나 해당 테마의 내장 그림을 사용합니다. 진행 트랙과 활성 카드 미니 마스코트는 `테마 전용 마스코트(mascot_<theme>) → 공통 마스코트(mascot) → 내장 SVG` 순으로 적용합니다. 도장 배지는 `테마 전용 도장(stamp_<theme>) → 공통 도장(stamp) → 테마 마스코트 합성 도장(.stamp-generated) → 내장 도장 SVG` 순으로 렌더링합니다.
- 4단계 카드 일러스트는 `개별 고정 사진(localStorage) → 현재 테마 IndexedDB 랜덤 풀(앱 열기·테마 전환·하루 변경 시 1회 고정) → 내장 SVG` 순으로 적용하며, 깨진 이미지는 `onerror` 시 내장 SVG로 자동 폴백합니다.
- 일반 도장은 약 120ms 시점에 착지음 한 번을 재생하고 약 310ms에 정착합니다. 다음 행동은 즉시 표시하고 180ms 뒤 짧게 강조합니다. 최초 입력 뒤 320ms 동안 다음 도장을 잠그며, 같은 제스처로 다른 도장이나 취소를 실행할 수 없습니다.
- 하루 첫 전체 완료는 네 도장과 “준비 끝! 이제 출발해요!”를 표시합니다. 마지막 카드의 작은 반짝임은 570ms 안에 끝납니다. 부모 설정에 따라 두 음 징글을 추가합니다. 취소 뒤 재완료와 새로고침에는 첫 축하를 반복하지 않습니다. 취소는 최근 도장만 복원하고 짧은 종이 소리를 재생합니다.
- 효과음 자동 재생, 전체 완료 징글, 화면 움직임 감소를 부모 설정에서 제어합니다. 세 종류의 효과음은 자동 재생이 꺼져 있어도 명시적으로 미리들을 수 있습니다. 시스템 또는 앱의 움직임 감소가 켜져 있으면 정적인 도장과 상태를 표시하고 GIF·WebP 대신 정적 그림을 사용합니다. 징글·움직임 설정과 첫 완료 날짜는 브라우저에 저장합니다. 이전 API 요청의 호환성을 위해 상태의 `ttsEnabled` 필드는 유지하며 브라우저의 도장 피드백은 효과음만 재생합니다.
- 앱과 함께 캐시하는 모노 WAV는 도장 120ms, 취소 90ms, 징글 340ms입니다. 도장음과 종이 소리는 CC0 녹음을 잘라 모노 변환하고 짧게 페이드했습니다. 징글은 두 음으로 새로 제작했습니다. [Stamp · kermite607](https://freesound.org/people/kermite607/sounds/362624/) · [Paper Rustle · BenjaminNelan](https://freesound.org/people/BenjaminNelan/sounds/353125/) · [CC0](https://creativecommons.org/publicdomain/zero/1.0/)
- 일괄 등록에서 `poster/`, `posters/` 폴더의 정지 미리보기는 제외합니다. 이미 저장된 미리보기도 랜덤 후보에서 제외합니다. 상어 가족의 한글 폴더는 가져올 때 활성 테마와 관계없이 아기상어로 분류합니다. 섹션 6 고정 그림이 랜덤 선택을 가리면 다시 뽑기 결과에 그 이유를 표시합니다.
- PWA 매니페스트는 192×192 및 512×512 PNG 설치 아이콘을 상대 경로로 제공합니다. 배포는 HTML과 연결된 CSS·JS·글꼴·효과음을 서비스 워커 버전과 함께 묶습니다. 기존 설치에서 새 묶음이 완전히 설치되면 `새 버전 적용`이 표시됩니다. 부모 설정에서 보드 종류와 현재 화면 버전을 확인합니다. 같은 주소에서 업데이트할 때 설정과 IndexedDB GIF를 보존합니다.
- 로컬 HTTP 서버(`app.server`)는 정적 PWA 파일 서빙과 함께 `/api/health`, `/api/state`(`GET`/`POST`)를 제공하며, 실행 상태는 `work/` 관제 원장과 분리된 `.local/dashboard_state.json`(`--state-file`로 변경 가능)에 저장합니다.
- 품질 검증은 `tests/test_fullstack.py`(루프백 통합 테스트, `contracts/api/dashboard_state.schema.json` JSON Schema 정합성, JS 단위 테스트, 배포 워크플로/SW 계약)와 `tests/test_browser_e2e.py`(Playwright Chromium 차일드 락·터치 홀드 해제 회귀·테마 영속성 E2E)로 수행하며, `.github/workflows/deploy-pages.yml`의 `verify` 잡 통과 후에만 `main` 브랜치 Pages 배포(`deploy` 잡)를 실행합니다.

공개 기본 보드는 정적 PWA이며 가족용 준비물 API를 호출하지 않습니다. 인증된 별도 출처의 가족 보드에서는 오른쪽 위 부모 설정 아래 `키즈노트` 아이콘으로 목록과 조회 상태를 엽니다. 항목이 없거나 확인이 필요해도 상세 창을 열 수 있고, 표시할 항목이 있을 때 강조합니다. 기능 계약은 [FEAT-002](FEAT-002-kidsnote-supplies.md), 현재 운영 상태와 남은 검증은 [운영 종합](../system/kidsnote-supplies-activation.md)을 따릅니다. 소스 통합이나 CI 통과만으로 운영 배포·실기기 적용 완료를 확정하지 않습니다.

## 날씨 표시와 측정 근거

가족 보드의 내일 예보는 내일의 서울 날짜, 날씨 상태, 최저·최고 기온을 오른쪽에 표시한다. 좁은 화면에서 기온과 날짜는 항목별로 읽을 수 있게 정렬한다. 오늘 기온, 내일 예보와 시간대별 기온은 Open-Meteo 응답에서 서울 날짜와 시각을 대조한다. 기온·날씨 코드·대기질 수치가 빠지면 해당 값을 미확인으로 표시한다.

가족 보드와 기본 보드 소스는 오늘 07:00~18:00 KST의 시간대별 강수확률이 모두 있는 경우에만 그 구간의 최댓값을 등원 안내에 쓴다. 관측 또는 현재 예보 시각이 1시간보다 오래되면 현재 수치를 표시하지 않는다. 저장된 예보는 3시간까지 적용일이 맞는 값만 사용한다. 자정에 날짜가 바뀌면 예보를 다시 확인한다. [Open-Meteo 응답 계약](https://open-meteo.com/en/docs)
