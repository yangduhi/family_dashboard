# 어린이집 등원 준비 가족 대시보드 설계서 (`family_dashboard`)

> **대상 기기:** 삼성 갤럭시 탭 S7 (11인치, 2560×1600, 16:10 가로 전체화면 기준)
> **관제 기준:** [project-control](file:///D:/vscode/project-control/AGENTS.md) (`v0.1.2`, `fullstack` 템플릿 및 4단계 검증 루프)

---

## 1. 목적 및 배경 (Intent & Why)
- **목적:** 매일 아침 딸아이가 어린이집 등원 준비 과정(`① 아침 먹기` → `② 세수·양치` → `③ 옷 입기` → `④ 가방 챙기기`)을 시각적으로 보면서, 스스로 하나씩 완수하고 **'쾅!' 도장**을 찍으며 성취감을 느끼도록 돕는 가족 대시보드 앱을 제작한다.
- **사용자 특성:** 앱 제작 경험이 없는 보호자가 관리·수정하기 쉬워야 하며, 아침 등원 시간에는 PC를 켜지 않아도 **갤럭시 탭 S7 단독**으로 즉시 켜서 사용할 수 있어야 한다. 또한 유아가 화면의 다른 곳을 아무리 만져도 오작동하지 않는 **엄격한 터치 제한(차일드 락)**이 필수적이다.

## 2. 목표 · 비목표 · 안티목표 (Goals, Non-Goals, Anti-Goals)

### 목표 (Goals)
1. **갤럭시 탭 S7 16:10 가로 화면 최적화:** 스크롤 없이 한 화면에 상단(시계·날씨·미세먼지·등원 복장 팁), 중단(출발 카운트다운·캐릭터 진행바), 하단(4단계 등원 준비 카드)이 선명하게 배치된다.
2. **키오스크 차일드 락 (엄격한 터치 제한):**
   - 화면 전체에서 스크롤, 확대/축소, 텍스트 선택, 우클릭/길게 누르기 컨텍스트 메뉴를 차단한다.
   - 일반 화면에는 테마 전환 탭을 노출하지 않고 **🔒 부모 설정(우측 상단 자물쇠 3초 길게 누르기)** 내부에 숨긴다.
   - 아이가 단일 탭으로 조작할 수 있는 영역은 **현재 진행 순서인 카드의 `[👆 완료! 도장 찍기]` 버튼 단 1곳**으로 제한한다.
3. **도장 '쾅!' 성취 연출 및 안전한 '취소(되돌리기)' 기능:**
   - 완료 버튼을 누르면 대형 캐릭터 도장이 위에서 날아와(`scale 2.6 → 1.0`) **'쾅!'** 찍히는 타격감 애니메이션, 카드 미세 흔들림, 테마별 파티클(물방울/눈꽃·별), 내장 효과음(Web Audio) 및 한국어 칭찬 음성(TTS)이 재생된다.
   - **실수 방지용 취소 기능:** 아이가 실수로 눌렀을 때 되돌릴 수 있도록, **가장 최근에 완료된 카드 우측 하단에 작은 `[↩ 도장 취소 (1.5초 꾹)]` 버튼**을 제공한다. 아이가 무심코 톡 건드리는 짧은 터치에는 풀리지 않고, **1.5초 동안 길게 누르면** 원형 게이지가 찬 뒤 도장이 취소되어 해당 단계로 돌아간다. (부모 설정 창 안에서도 `[방금 도장 취소]` 및 `[오늘 도장 전체 초기화]` 버튼을 즉시 사용할 수 있다.)
4. **아기상어 · 뽀로로 2가지 테마 지원 (부모 설정 내 전환):**
   - **🦈 아기상어 테마:** 에메랄드·오션블루 배경, 노란 상어 포인트, 진행바 상어 이동, 버블 파티클, 아기상어 왕도장.
   - **🐧 뽀로로 테마:** 스카이블루·눈꽃 화이트 배경, 주황/노랑 헬멧 포인트, 진행바 펭귄 이동, 별·눈꽃 파티클, 뽀로로 대장 왕도장.
5. **일러스트 기본 내장 + 일반 사진(`PNG`/`JPG`) 간편 교체:**
   - 사용자가 별도로 SVG를 준비하지 않아도 즉시 쓸 수 있도록 **4단계 동작 일러스트 및 테마별 캐릭터/도장 SVG 그래픽을 앱에 기본 내장**한다.
   - 사용자가 원할 때 실제 아기상어/뽀로로 그림이나 아이 사진(`PNG`, `JPG`, `WEBP`, `GIF`, `SVG` 모두 지원)으로 쉽게 바꿀 수 있도록 **🔒 부모 설정 내 `[📷 그림/사진 바꾸기]`(태블릿 갤러리에서 선택해 브라우저 내부 저장)** 기능과 `web/assets/custom/` 폴더 교체 방식을 함께 제공한다.
6. **`project-control` 표준 준수:** `D:\vscode\family_dashboard`를 `project-control init --template fullstack`으로 생성하고, `begin → 구현·테스트 → verify → record-review → refresh` 4단계 루프를 통과시킨다.

### 비목표 (Non-Goals)
- 외부 유료 기상 API 키 발급이나 복잡한 클라우드 DB/회원가입 서버 구축은 하지 않는다. (인증키가 필요 없는 Open-Meteo 무료 날씨·대기질 API와 브라우저 로컬 저장소 `localStorage`/`IndexedDB`를 사용한다.)
- Google Play 스토어 출시용 네이티브 안드로이드(Kotlin/Flutter) APK 빌드는 포함하지 않는다.

### 안티목표 (Anti-Goals — 기술적으로 작동해도 실패로 간주하는 상태)
- 아이가 화면 아무 곳이나 연타했을 때 테마가 바뀌거나, 화면이 확대/스크롤되거나, 이미 찍은 도장이 단발 터치로 쉽게 풀려버리는 상태.
- 매일 아침 등원 때마다 부모가 데스크톱 PC를 먼저 부팅해야만 태블릿 화면이 열리는 상태.
- 사용자가 직접 그래픽 툴로 SVG 파일을 구해 넣기 전까지는 빈 네모 박스만 나오는 상태.

## 5. 확정된 상세 화면 및 동작 명세

### 5.1 화면 레이아웃 (갤럭시 탭 S7 가로 16:10)
불필요한 상단 테마 배지 바를 제거하고, 시계·날씨 영역부터 바로 시작하여 4단계 준비 카드의 세로 공간과 시인성을 극대화한다. 부모 설정 진입용 작은 자물쇠(`🔒`)는 우측 상단 모서리에만 조용히 배치한다.

### 5.2 터치 제어 · 도장 찍기 · 도장 취소 규칙
1. **현재 순서 카드 (`ACTIVE`)**
   - 노란색/주황색 강조 테두리와 `"같이 하자!"` 말풍선, 캐릭터 마스코트가 표시된다.
   - 카드 하단의 큼직한 **`[👆 완료! 도장 찍기]`** 버튼만 단일 터치(탭)를 허용한다.
   - 터치 즉시:
     - 대형 원형 캐릭터 도장이 `scale(2.6) rotate(-18deg)`에서 `scale(1.0) rotate(-6deg)`로 내려찍히는 스프링 모션 실행
     - 카드 및 화면 미세 임팩트 진동(`keyframes stamp-shake`) + 테마 파티클(버블 또는 눈꽃/별) 24개 분출
     - Web Audio 합성 `'쾅!'` 저음 임팩트 + 밝은 3화음 차임벨 + 한국어 TTS 칭찬 음성 재생
     - 다음 번호 카드가 자동으로 `ACTIVE`로 전환되며, 진행바의 캐릭터가 25%씩 어린이집 아이콘 쪽으로 전진
2. **완료된 카드 (`COMPLETED`) — 안전한 취소 기능**
   - 단순 탭(짧은 터치)에는 아무 반응도 하지 않아 아이가 연타해도 도장이 풀리지 않는다.
   - **가장 마지막으로 완료한 카드** 하단에만 작고 차분한 **`[↩ 도장 취소 (1.5초 꾹)]`** 버튼이 표시된다.
   - 이 버튼을 **1.5초 동안 누르고 있으면** 원형 진행 링이 차오르며 해당 카드의 도장이 취소되고 다시 현재 순서(`ACTIVE`)로 되돌아간다. (중간에 손을 떼면 취소되지 않는다.)
   - 4단계 모두 완료되어 축하 화면이 뜬 상태에서도 우측 하단의 **`[↩ 마지막 도장 취소 (1.5초 꾹)]`**으로 언제든 4번 카드로 되돌릴 수 있다.
3. **대기 중인 카드 (`LOCKED`)**
   - 반투명 차분한 상태로 표시되며 어떤 터치에도 반응하지 않는다.
4. **자정 자동 초기화**
   - 날짜(`YYYY-MM-DD`)가 바뀌면 전날 찍은 도장 상태는 아침에 자동으로 `0/4` 초기 상태로 리셋된다.

### 5.3 🔒 부모 설정 모달 (우측 상단 자물쇠 3초 길게 누르기)
부모 설정 모달 안에서만 아래 항목을 조작할 수 있다:
1. **테마 버전 선택:** `[🦈 아기상어 버전]` ↔ `[🐧 뽀로로 버전]` 즉시 전환
2. **아이 이름 및 출발 시각:** 예: 이름 `"하은"`, 목표 출발 시각 `"08:50"`, 준비 시작 시각 `"07:50"`
3. **도장 수동 제어:** `[↩ 방금 도장 1단계 취소]`, `[🔄 오늘 도장 전체 초기화]`, 각 단계 개별 완료/해제 토글
4. **우리 동네 날씨 위치 설정:** 기본 주요 도시/구 프리셋 선택 또는 위도·경도 입력 (`Open-Meteo` 실시간 기온·강수확률·초미세먼지 PM2.5/PM10 연동)
5. **효과음 / 칭찬 음성(TTS) 켜기·끄기 및 테스트 버튼**
6. **그림/사진 커스텀 교체:** 기본 내장 SVG 일러스트 외에, 태블릿에 저장된 일반 이미지(`PNG`, `JPG`, `GIF`, `WEBP`, `SVG`)를 캐릭터 마스코트·도장·4단계 카드별로 업로드/초기화하는 기능
7. **갤럭시 탭 전체화면(Fullscreen) 전환 & 화면 꺼짐 방지(Wake Lock) 상태 표시**

## 6. 구현자 재량 결정 사항 (Builder Calls)
- **초기 기본값:** 아이 이름 `"우리 딸"`, 출발 시각 `"08:50"`, 준비 시작 `"07:50"`, 기본 위치 `"서울 (37.5665, 126.9780)"`, 기본 테마 `"아기상어"`로 설정하되 부모 설정에서 언제든 바꿀 수 있게 한다.
- **기술 스택:** 외부 빌드 도구(Webpack/Vite) 없이도 초보자가 바로 열어보고 수정할 수 있도록 표준 HTML5 + CSS3 + Vanilla ES Modules(`web/index.html`, `web/styles.css`, `web/app.js`, `web/assets.js`, `web/manifest.json`, `web/sw.js`)와 Python 표준 라이브러리 기반 로컬 서버(`src/app/server.py`)로 구성한다.
- **태블릿 단독 배포 지원:** 탭 S7 단독 실행을 위해 PWA 매니페스트(`display: fullscreen`, `orientation: landscape`)와 오프라인 서비스 워커(`sw.js`)를 포함하며, PC 없이도 사용할 수 있도록 안내 가이드를 제공한다.
