# DESIGN — family_dashboard

갤럭시 탭 S7(16:10 가로) 환경의 정보 우선순위, 터치 가드, 테마 및 시각 하니스 기준을 요약합니다. 현재 기본 화면 계약은 [FEAT-001](../features/FEAT-001-initial.md), 가족 준비물 계약은 [FEAT-002](../features/FEAT-002-kidsnote-supplies.md)를 따릅니다.

## 1. 화면 우선순위와 차일드 락
- 헤더 왼쪽에 시계를 두고, 최대 630px의 날씨 카드를 오른쪽 부모 설정·키즈노트 아이콘 열에 맞춥니다. 키즈노트 아이콘은 준비물 상태를 열며, 항목이 있을 때 점과 테두리로 강조됩니다. 화면이 좁아지면 날씨가 아래로 이동합니다.
- 날씨·진행률·준비 카드·상세와 설정의 카드에 테마 배경색을 사용합니다. 아기상어는 햇살 노랑, 뽀로로는 하늘색을 기준으로 밝기와 채도를 나눠 현재 행동과 대기 상태를 구분합니다. 한 겹의 테마색 윤곽으로 투명한 시계 배경에서 선택한 테마 캐릭터가 보이도록 합니다.
- 날씨 카드는 날짜와 현재 기온, 시간별 기온, 내일 예보의 세 영역을 갖습니다. 현재 기온에 가장 큰 글자를 사용하고, 시간별 기온은 네 칸으로 정렬하며 내일 예보에는 테마색 배경을 씁니다. 카드 하단의 등원·하원은 체감온도와 강수확률을 같은 열에 맞춥니다. 강수확률에는 물방울 아이콘을 붙이고 미세먼지 등급은 상태 배지로 표시합니다. 서울 기준 내일 예보를 확인할 수 없으면 숫자를 표시하지 않습니다.
- 상단 시계·날씨·카운트다운 헤더, 중앙 진행 트랙(어린이집 간판 목표 아이콘), 하단 4단계 카드 순으로 단일 화면(무스크롤)에 배치합니다.
- 현재 활성 단계 카드(`.is-active`)는 5px 강조 테두리·미세 확대·발광으로 부각하고, 대기 카드(`.is-locked`)와 완료 카드(`.is-done`)는 투명도와 채도를 낮춰 아이 시선이 현재 단계에 집중되게 합니다(4단계 모두 완료 시 전체 밝기 복원).
- 가로 4열 화면에서는 카드 하단에 여유를 두어 그림·제목·완료 버튼을 위로 배치합니다. 그림 표시 한도를 20% 늘리고 카드의 가용 폭과 높이에 맞춰 조절합니다.
- `.dashboard-shell`은 `pointer-events: none`으로 잠그고, 현재 활성 카드의 `[👆 완료! 도장 찍기]`, 직전 완료 카드의 1.5초 취소 버튼, 우측 상단 3초 부모 설정 자물쇠(`🔒`), 가족용 보드의 `키즈노트` 버튼과 열린 상세 창에 상호작용을 허용합니다.
- 터치 해제 시 오동작 방지를 위해 완료 버튼은 `pointerId` 일치 여부를 검사하고, 부모 설정 모달은 백드롭에서 시작된 포인터만 닫힘을 허용합니다.

## 2. 테마와 하니스 연결
- `babyshark`(기본)와 `pororo` 테마 전환은 부모 설정 모달 내부로 은닉하며, 시계 배경과 진행률·카드 마스코트는 `object-fit: contain`으로 잘림 없이 표시합니다.
- 마스코트·도장은 테마 전용 슬롯(`mascot_<theme>`, `stamp_<theme>`)과 기존 공통 슬롯(`mascot`, `stamp`) 폴백을 지원하고, 카드 일러스트는 `개별 고정 사진 → 테마별 IndexedDB 랜덤 GIF/WebP(앱 열기·테마 전환·하루 변경 시 1회 고정) → 내장 SVG` 순으로 렌더링하며 오류 시 내장 SVG로 폴백합니다.
- 현재 `config/workflow.toml`의 시각 픽셀 비교(`harness.screens`)는 기준선(B0) 승격 전까지 `NOT_APPLICABLE`로 두고 Playwright 브라우저 E2E로 상호작용 회귀를 검증합니다.

## 3. 공개·가족 화면과 검증 경계
- 공개 기본 보드는 가족 준비물 조회를 제공하지 않습니다. 인증된 가족 보드의 아이콘은 0건·확인 필요·로그인 필요 상태에서도 상세 창을 엽니다. 항목 강조와 상태 조회 가능 여부를 구분합니다.
- 공개 기본 호칭은 `친구야`이며 편집한 호칭은 기기에 보존합니다. 공개 문서·검증 화면에는 실제 호칭이나 가정의 정밀 위치를 넣지 않습니다.
- 소스의 레이아웃과 실제 배포 화면을 구분합니다. 기존 서비스 워커에서 업데이트, 인증 만료, 오프라인 및 좁은 화면을 확인하고 S7 실기기 결과를 별도로 기록합니다. 최신 운영 근거는 [운영 종합](kidsnote-supplies-activation.md)을 따릅니다.
