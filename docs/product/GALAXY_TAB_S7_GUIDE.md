# 갤럭시 탭 S7 설치·배포 및 유지보수 가이드

> HTTPS로 설치한 PWA는 정적 자산을 캐시한 뒤 PC 없이 실행할 수 있습니다. 새 버전은 다운로드와 설치가 완료된 뒤 적용합니다. 가족 보드의 준비물 조회에는 인증과 네트워크가 필요합니다.

---

## 1. 무료 HTTPS 배포로 PC 전원 OFF + 자동 업데이트 설정하기 (GitHub Pages 기준)

이 프로젝트에는 이미 GitHub Pages 자동 배포 설정([deploy-pages.yml](../../.github/workflows/deploy-pages.yml))이 들어 있습니다.

### 최초 1회 설정
1. GitHub([github.com](https://github.com))에서 무료 계정 로그인 후 새 저장소(예: `family_dashboard`, **Public** 권장 — 무료 계정에서 Pages 사용 가능)를 만듭니다.
   - *(개인정보 안내)* 정적 PWA의 사용자 호칭·설정·사진은 해당 브라우저의 `localStorage`·`IndexedDB`에 저장됩니다. 날씨 조회에는 앱에 설정한 서울 지역 좌표를 사용합니다. 공개 문서에는 개인 호칭·정밀 위치·가족 보드 주소를 기록하지 않습니다. 로컬 개발 서버의 상태 API는 별도 상태 파일을 사용합니다.
2. 이 프로젝트 폴더를 GitHub 저장소에 올립니다(`git push -u origin main`).
3. GitHub 저장소 상단 **Settings → Pages → Build and deployment → Source**를 **`GitHub Actions`**로 선택합니다.
4. 배포가 완료되면 HTTPS 주소를 확인합니다. 이 저장소의 배포 주소는 [등원 준비 대시보드](https://yangduhi.github.io/family_dashboard/)입니다.

### 갤럭시 탭 S7에 앱 설치 (최초 1회)
1. 갤럭시 탭 S7을 가로로 놓고 **삼성 인터넷** 또는 **Chrome**에서 위 HTTPS 주소를 인터넷에 연결한 상태로 엽니다.
2. 브라우저 메뉴(`⋮` 또는 `≡`) → **`현재 페이지 추가` → `홈 화면`** (또는 **`앱 설치`**)을 누릅니다.
3. 이제 태블릿 바탕화면 아이콘을 누르면 **PC가 꺼져 있어도, 태블릿을 재부팅해도** 주소창 없는 전체화면 앱으로 바로 실행됩니다.

### 이후 유지보수(업데이트) 방법
- 승인된 변경을 검증하고 배포하면 태블릿이 새 정적 자산을 내려받습니다. 새 묶음의 설치가 끝나고 **새 버전 적용**이 표시되면 누릅니다. 일부 자산 다운로드가 실패한 상태를 업데이트 완료로 판단하지 않습니다. 부모 설정에서 보드 종류와 현재 화면 버전을 확인합니다. 배포 계약은 [워크플로](../../.github/workflows/deploy-pages.yml)와 [서비스 워커](../../web/sw.js)를 따릅니다.

## 2. (개발·테스트용) PC에서 수정 직후 미리 확인하기
웹에 올리기 전에 PC나 태블릿에서 먼저 시험해 보고 싶을 때만 프로젝트 전용 가상환경(`.venv`)으로 로컬 서버를 켭니다.

최초 1회 환경 준비(프로젝트 루트에서 실행):
```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

로컬 미리보기 서버 실행:
```powershell
.\.venv\Scripts\python.exe -m app.server --host 0.0.0.0 --port 8080
```
- 상태 파일은 기본으로 `.local\dashboard_state.json`에 저장되며 `--state-file`로 변경할 수 있습니다.
- PC 브라우저에서 `http://127.0.0.1:8080` 또는 같은 Wi-Fi 태블릿에서 `http://<PC_IP>:8080`으로 바로 확인할 수 있습니다.

## 3. 아이 사용법 & 부모 설정 열기
1. **아이 조작:**
   - 현재 순서 카드의 **`[👆 완료! 도장 찍기]`** 버튼을 누릅니다. 가족 보드는 별도의 **키즈노트** 아이콘으로 조회 상태와 목록을 엽니다.
   - 시계·날씨·진행바·다른 카드는 터치해도 움직이지 않습니다.
2. **실수로 도장을 찍었을 때 (1.5초 길게 눌러 취소):**
   - 가장 최근 완료한 카드 아래 작은 **`[↩ 도장 취소 (1.5초 꾹)]`** 버튼을 **1.5초 동안 꾹 누르고 있으면** 원형 게이지가 찬 뒤 직전 도장만 취소됩니다. (짧게 누르면 취소되지 않습니다.)
3. **🔒 부모 설정 열기 (3초 길게 누르기):**
   - 화면 오른쪽 위 작은 **`🔒`** 자물쇠 아이콘을 **3초 동안 꾹 누르고 있으면** 부모 설정 창이 열립니다.
   - 부모 설정 안에서만 다음을 바꿀 수 있습니다:
     - **테마 변경:** `[🦈 아기상어 버전]` ↔ `[🐧 뽀로로 버전]`
      - **호칭·출발 시각:** 기본 호칭 `친구야`를 원하는 호칭으로 바꿀 수 있습니다. 기존 기기에 저장한 사용자 호칭은 유지됩니다.
      - **날씨:** 앱에 설정한 서울 지역의 기온·미세먼지·옷차림 안내를 제공합니다. 값이 확인되지 않으면 미확인으로 표시합니다.
     - **테마별 행동 GIF·WebP 랜덤 풀:** 태블릿 브라우저 내부(`IndexedDB`)에만 보관되며, 부모 설정에서 ZIP 묶음(`morning_routine_*`, `pororo_morning_*` 등)을 일괄 가져오거나 4단계별로 여러 파일을 추가할 수 있습니다. (앱 열기·테마 전환·하루 변경 시 1회 랜덤 고정, `[🎲 오늘 그림 다시 뽑기]`로 즉시 변경 가능)
      - **테마별 마스코트·도장 교체:** 부모 설정에서 테마별 전용 슬롯에 그림을 등록합니다. 시계 배경은 선택한 테마의 전용 그림이나 내장 그림을 사용하며, 진행률·카드·도장은 각 슬롯의 폴백 규칙을 따릅니다.
     - **효과음과 화면 움직임:** 효과음 자동 재생, 전체 완료 징글, 화면 움직임 줄이기를 설정합니다. 도장음·전체 완료음·취소음은 각각 미리들을 수 있습니다.

### 갤럭시 탭 S7에서 효과 비교하기

1. 평소 거치 위치에서 내장 스피커를 사용합니다. 같은 미디어 음량으로 도장음과 전체 완료음을 조용할 때와 평소 아침 소음 속에서 각각 듣습니다.
2. 미리듣기를 열지 않고 첫 도장을 찍습니다. 온라인에서 앱을 연 뒤 비행기 모드로 완전히 닫았다가 다시 열어 효과음과 진행을 확인합니다.
3. 전체 완료 직후 취소한 뒤 다시 찍어 징글이 반복되지 않는지 확인합니다. 효과음 자동 재생을 끄고 화면 움직임을 줄여도 다음 행동과 출발 안내를 찾을 수 있어야 합니다.
4. 징글 켬과 끔을 아침에 한 번씩 번갈아 사용해 봅니다. 시간이 되면 `켬 → 끔 → 끔 → 켬`으로 비교합니다. 다음 행동 시작까지 걸리는 시간, 재탭, 보호자의 추가 안내, 놀람 여부를 비교합니다.

## 4. (선택) 태블릿 '화면 고정'으로 홈·뒤로가기 버튼까지 잠그기
1. 탭 S7 **설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → 화면 고정(Pin windows)** 켜기
2. 대시보드 앱을 연 뒤 최근 앱(`|||`) 버튼 → 상단 앱 아이콘 터치 → **이 앱 고정** 선택
   *(해제할 때는 `|||` + `<` 버튼을 동시에 길게 누르면 됩니다.)*

## 5. 가족 보드의 키즈노트 준비물 확인

1. 보호자가 별도로 안내받은 가족 보드 주소에 로그인합니다. 공개 기본 보드와 가족 보드는 다른 출처입니다. 가족 주소는 공개 문서에 기록하지 않습니다.
2. 오른쪽 위 설정 아래 **키즈노트** 아이콘을 누릅니다. 준비물 또는 현재 조회 상태를 확인합니다. 항목이 있으면 강조되며, 0건이어도 상세 창을 열 수 있습니다. `가족 보드 로그인 필요`이면 상세 창의 로그인 안내를 따릅니다. `키즈노트 재인증 필요`이면 보호자가 수집 계정 상태를 점검합니다.
3. Chrome에서 **가족 등원 보드**로 설치합니다. 기존 공개 앱 아이콘은 이전 주소를 계속 엽니다. 가족 주소를 처음 사용할 때는 GIF·호칭·출발 시각·테마를 새 출처에 등록합니다. 같은 가족 주소의 업데이트에서는 기존 설정과 GIF를 보존합니다.
4. 이전 설치 화면이 계속 보이면 안내받은 가족 주소를 직접 열고 부모 설정의 보드 종류·화면 버전을 확인합니다. **새 버전 적용**이 보이면 적용합니다. 기존 공개 PWA의 사이트 데이터를 지우지 않고 두 주소를 구분해 확인합니다.
5. 날씨 카드의 **내일**에서 서울 적용일·최저·최고 기온을 확인합니다. 07:00–08:00 KST에는 준비물의 적용일·출처·확인 시각을 확인합니다. `확인 필요`는 준비물 없음과 다릅니다. 인증이 만료돼도 기존 4단계 화면이 동작하는지 확인합니다.

기존 서비스 워커가 제어한 동일 출처에서 새 버전을 적용하고 설정·GIF 보존과 오프라인 재실행을 확인해야 합니다. 인증된 브라우저 확인과 S7 홈 화면 아이콘의 실제 실행·터치 검증은 별도입니다. 자연 예약의 06:00 KST 게시 마감도 수동 게시로 대체하지 않습니다. 최신 결과와 남은 통과 기준은 [운영 종합](../system/kidsnote-supplies-activation.md)에 기록합니다.
