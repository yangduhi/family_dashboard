# Product Requirements Document (PRD) — family_dashboard

## 1. 목적 및 범위
- 이 문서는 삼성 **갤럭시 탭 S7 (16:10 가로 화면)**에 비치해 아이가 매일 아침 어린이집 등원 준비(`① 아침 먹기 → ② 세수·양치 → ③ 옷 입기 → ④ 가방 챙기기`)를 스스로 완수하도록 돕는 가족 대시보드 앱(`family_dashboard`)의 기준 원본입니다.
- 아침 등원 시간에는 PC를 켜지 않아도 태블릿 단독(PWA + 로컬 저장소 + 무료 기상 API)으로 즉시 동작하며, 개발·품질 검증은 `project-control` 표준 4단계 루프로 관리합니다.

## 2. 핵심 요구사항
1. **엄격한 터치 제한(차일드 락):** 대시보드 화면의 스크롤·확대/축소·텍스트 선택을 차단한다. 단계 카드는 현재 순서의 **`[👆 완료! 도장 찍기]`** 버튼에만 단일 터치를 허용한다. 가족용 보드는 `키즈노트` 버튼에 단일 터치를 허용한다.
2. **도장 착지와 안전한 취소:** 완료 터치에 짧은 착지음과 캐릭터 도장을 표시하고 다음 행동 그림을 강조한다. 그날 첫 전체 완료에는 출발 안내, 마지막 카드의 짧은 반짝임, 선택형 징글을 제공한다. 실수 복구는 최근 완료 카드에서 **1.5초 길게 누르기**로 수행한다. 무음과 움직임 감소에서도 완료 도장, 현재 행동, 출발 안내를 확인할 수 있게 한다.
3. **은닉된 부모 설정 (`🔒 3초 꾹`):** 우측 상단 자물쇠를 3초 길게 눌러 부모 설정을 연다. 테마, 호칭, 출발 시각, 도장 초기화, 행동 애니메이션 풀과 개별 그림을 편집한다. 공개 기본 호칭은 `친구야`이며 기기별 사용자 호칭을 보존한다. 날씨는 앱에 설정한 서울 지역을 사용한다. 공개 문서에는 개인 호칭이나 가정의 정밀 위치를 기록하지 않는다.
4. **내장 일러스트 & 태블릿 전용 랜덤 풀 (`IndexedDB`):** 별도 이미지를 준비하지 않아도 즉시 실행 가능한 고화질 SVG 일러스트를 내장하고, 공개 저장소 저작권 회피를 위해 캐릭터 행동 `GIF`/`WEBP` 파일은 태블릿 브라우저 내부(`IndexedDB`)에만 다중·ZIP 업로드해 보관하며 **앱 열기·테마 전환·하루 변경 시 1회 랜덤 고정**으로 표시한다.
5. **가족 보드의 당일 준비물:** 승인된 공지·알림장에서 확인한 준비물과 적용일을 비공개 DB에 보관한다. 정정·취소를 반영한 유효한 당일 결과를 06:00 KST까지 게시하는 것이 목표다. 07:00–08:00 KST에는 우측 상단 설정 아래 `키즈노트` 아이콘에서 전체 목록과 조회 상태를 확인한다. 표시할 항목이 있으면 강조하며, 0건이어도 상세 창을 열 수 있다. 자료 부족과 검증된 `EMPTY`를 구분하고 당일 확인 전에는 예정 항목의 출처·최근 확인 시각을 표시한다. 준비물 응답은 기기 영속 저장소에 저장하지 않는다. 공개 기본 보드는 이 API를 호출하지 않는다.

## 4. 운영 현황

공개 기본 보드와 인증된 가족 보드는 별도 출처로 운영한다. 출처를 처음 옮길 때 브라우저 설정과 GIF는 자동 이전되지 않는다. 같은 출처의 업데이트에서는 설정과 GIF를 보존한다. 최신 운영 상태와 남은 자료 충분성·자연 예약 마감·기존 설치 업데이트·S7 실기기 검증은 [운영 종합](../system/kidsnote-supplies-activation.md)에서 관리한다. 과거 계획이나 테스트 수치를 현재 운영 완료의 근거로 사용하지 않는다.
