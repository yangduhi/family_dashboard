# Product Requirements Document (PRD) — family_dashboard

## 1. 목적 및 범위
- 이 문서는 삼성 **갤럭시 탭 S7 (16:10 가로 화면)**에 비치해 딸아이가 매일 아침 어린이집 등원 준비(`① 아침 먹기 → ② 세수·양치 → ③ 옷 입기 → ④ 가방 챙기기`)를 스스로 완수하도록 돕는 가족 대시보드 앱(`family_dashboard`)의 기준 원본입니다.
- 아침 등원 시간에는 PC를 켜지 않아도 태블릿 단독(PWA + 로컬 저장소 + 무료 기상 API)으로 즉시 동작하며, 개발·품질 검증은 `project-control` 표준 4단계 루프로 관리합니다.

## 2. 핵심 요구사항
1. **엄격한 터치 제한(차일드 락):** 화면 스크롤·확대/축소·텍스트 선택을 차단하고, 아이가 단일 터치로 누를 수 있는 영역은 **현재 순서 카드의 `[👆 완료! 도장 찍기]` 버튼 단 1곳**으로 제한한다.
2. **도장 '쾅!' 성취 연출 & 안전한 취소:** 완료 터치 시 대형 캐릭터 도장 타격 애니메이션 + 파티클 + Web Audio 효과음 + 한국어 TTS 칭찬 음성이 나오며, 실수 복구를 위해 최근 완료 카드에 **1.5초 길게 눌러야 동작하는 `[↩ 도장 취소 (1.5초 꾹)]`** 버튼을 제공한다.
3. **은닉된 부모 설정 (`🔒 3초 꾹`):** 불필요한 상단 테마 배지 바 없이 시계·날씨 헤더부터 바로 시작하며, `[🦈 아기상어 | 🐧 뽀로로]` 테마 전환과 아이 이름·출발 시각·도장 초기화·행동 애니메이션 풀(`IndexedDB`) 및 개별 그림/사진 교체는 **우측 상단 `🔒` 자물쇠를 3초 길게 눌러 여는 부모 설정** 안에 숨긴다. 날씨는 **서울특별시 강동구 상일동** 좌표(`37.5566, 127.1654`)로 고정한다.
4. **내장 일러스트 & 태블릿 전용 랜덤 풀 (`IndexedDB`):** 별도 이미지를 준비하지 않아도 즉시 실행 가능한 고화질 SVG 일러스트를 내장하고, 공개 저장소 저작권 회피를 위해 캐릭터 행동 `GIF`/`WEBP` 파일은 태블릿 브라우저 내부(`IndexedDB`)에만 다중·ZIP 업로드해 보관하며 **앱 열기·테마 전환·하루 변경 시 1회 랜덤 고정**으로 표시한다.
